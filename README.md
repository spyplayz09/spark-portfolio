SPARK.DEV PORTFOLIO
===================

A responsive, single-page portfolio website for Spark.

HOW TO USE
1. Extract the ZIP file.
2. Open index.html in a browser to preview.
3. Upload index.html to any static hosting provider (GitHub Pages, Netlify, Vercel, etc.).
4. Replace the sample project descriptions with your real project details and add your project URLs when ready.

CUSTOMIZATION
- Main theme colors are defined near the top of the <style> section in :root.
- Contact email is currently set to itsmesparkop@gmail.com.
- The site uses Google Fonts (Manrope and DM Mono); a network connection is needed to load them.
- No build tools or dependencies are required.

Note: Project cards and experience copy are editable portfolio starter content. Update them to accurately represent your published work.

SERVER LOGOS
The assets/ folder contains the three supplied featured server logos. Keep the folder beside index.html when uploading/deploying.
